A simple and elegant Weather Application that allows users to check real-time weather information for any location using the WeatherAPI.
The app includes automatic day/night mode, dynamic UI, and displays temperature, conditions, and local time.

Features
✔️ Search Any Location

Enter a city or country name and instantly get accurate weather details.

✔️ Real-Time Weather Data

Powered by WeatherAPI to fetch:

Temperature (°C)

Weather condition

Weather icon

Local time

Country & City

Day/Night detection

✔️ Auto Day/Night Mode

The UI automatically switches to dark mode at night and light mode during the day, based on the weather API response.

✔️ Clean UI

Simple, minimal, and responsive design suitable for beginners and professionals.
